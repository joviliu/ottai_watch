# 表盘 0.1.15：Signal 电子数字、Meridian 大圆盘及三款统一配色

2026-10-29。手机镜像仍为 0.1.11/code12；RPK 新增图表基准线的版本见 [watch-0.1.12](../watch-0.1.12/README.md)，表盘文件协议不变。

- Ultra：保留原点阵布局、32 组配色与灰色更新时间，本轮无需再覆盖已装 0.1.14。
- Signal：时间/血糖改用原创七段电子数字，缩小血糖字号、使用浅紫色正常值，保留信息卡布局。
- Meridian：圆盘从 328 扩到 408 像素、接近屏幕宽度；血糖/趋势/原始时间叠在盘面下部，指标在下方。时针仍有 720 个位置、分针 60 个位置，没有降低时间精度或新增秒针。
- 三款统一使用 32 组协调双色，04/11/15/19 换组。Signal 数字与 Meridian 指针通过图像样式变色复用图片，不生成 32 套指针；不支持该属性的旧引擎以 pcall 保留原固定色。日期/原始时间及血糖紫/黄/红规则不受时钟配色影响。
