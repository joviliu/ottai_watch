# Mac 0.3.0：动态24h与固定日报

2026-11-10，macOS15+，arm64/x86_64。主应用和WidgetKit扩展在`OttaiMirror-0.3.0-macos.zip`中，本地ad-hoc签名，未notarize。手机沿用0.2.0，不需升级手表应用/表盘。

- 「动态24h」：截至最新测量的滚动24小时，完整性就绪后主动分析；至少间隔30min、无额外每天3次限制（理论最多48次），同快照复用。失败/不确定结果不自动重发。
- 「每日回顾」：每天08:15分析前一自然日00:00–24:00（Asia/Shanghai），累计真实资料超过72h后运行。两份报告独立保留，在同一个文字区切换，各自显示时窗。
- 报告包括整体水平、波动、候选餐后样上升/回落幅度和分钟、健康人群研究参考、近期/更早个人完整日比较。机制和饮食只作有替代解释的参考性假设；来源和边界见[科学方法v2](../../docs/CGM_ANALYSIS_METHOD.md)。
- 刷新改为无背景图标（点击轻转一圈）；主页连接卡移除，左下「设置…」打开独立窗口。

手动完整性门槛：源跨度24h、最近24h覆盖≥95%、最长未观测缺口≤15min、最新读数10min内。这是产品门槛，不是医学验证标准。当前正式资料尚不足24h，按钮正确禁用并显示原因；不会用假数据提前解锁。

实际Mac已验证页签切换、刷新图标、独立设置窗口。服务在本地和Ali Python3.6通过测试，覆盖并发幂等、持久30min间隔、一天超过3次、两类报告并存、前一自然日边界、角色隔离、候选事件/缺口/未完成恢复。临时合成数据库通过一次真实模型调用并返回5章节；未混入正式资料。这不代替24h真实资料的第一份个人报告或多日稳定性验收。

## 安装与配置

```sh
sh macos/build.sh
sh macos/install.sh --import-config /absolute/private-config.json
```

主应用的私密配置可含独立`analysisToken`（至少32字符），配对服务器`ANALYZE_TOKEN`。安装器向Widget配置时主动剥除它，只读token不能上传或请求模型。包内不含任何凭据或健康数据；已配置环境可直接`sh macos/install.sh`。详见[Mac说明](../../macos/README.md)和[部署接续](../../docs/CLOUD_SYNC_HANDOFF.md)。

```sh
cd releases/cloud-0.3.0
shasum -a 256 -c SHA256SUMS
```
