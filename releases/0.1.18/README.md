# 表盘 0.1.18：配色随机选择的低精度修复（待真机覆盖）

2026-10-30。三款共用的选色器存在数值精度兼容性缺陷，本版修复选色运算。保留 Ultra 点阵、Signal Poiret One、Meridian 极简指针及各自字号/布局；配色库仍为原 32 组，切换点仍为当地 04/11/15/19，同段稳定、午夜延续、相邻段不重复。日间与隔日偶然同色仍可发生，不承诺隔日永不重复。

## 检查与修复

- 三款已发布 BIN 的选色函数与旧源码一致，日期确实参与种子，桌面 64 位 Lua 中并非每天固定相同。
- 旧乘法产生超过 32 位整数和单精度精确范围的大数。在真实单精度 Lua 5.2 中，直接运行原函数会退化为每天相同的两组交替；32 位整数 Lua 5.3 的结果也与桌面不一致。这是可复现的兼容性缺陷，与用户现象吻合，但未读取本表固件的实际 Lua 数值配置，不能直接认定现场根因已被确认。
- 改用模 65521 的小整数混合，最大迭代中间值 16,459,369 < 2^24，两种低精度模式都能精确执行；不增加存储、定时器、蓝牙请求或随机状态。

先核对 SHA256SUMS。三款 BIN/ZIP 与 manifest 均已生成；字体、PNG、布局、帧模型和选择器预览逐文件核对一致。Signal/Meridian 只有 main.lua 变化；Ultra 同步当前共享 Lua，clock-palettes.lua 另增加原生指针使用的数字颜色字段，32 组名称、顺序和实际图片均保持一致。

新增回归先在旧算法失败，再于修复后通过：1,152 个跨日/跨年/闰日案例在桌面、float32 Lua 5.2、int32 Lua 5.3 中逐项一致，检查各时段多样性、全部 32 组可达及无短期固定日循环。原 UI/帧/全天资源/打包测试通过，UI 另在上海和纽约时区通过；CI 会编译校验固定版本的两种低精度 VM。

**本版尚未真机安装。** 上述算术测试替换 os.date 提供日历字段，真实日期实现、跨日颜色和手表屏显仍须统一覆盖后观察。手机 APK 0.1.11、RPK 0.1.12 与已恢复的官方运动健康 3.59.2 均未改动。保持既有连接，不解绑/重置；侧载方法及官方安装边界见 [交接](../../docs/HANDOFF.md) 和 [安装](../../docs/install.md)。
