# 自动睡眠与锻炼区间 0.7.0

手机Android0.7.0/code21、Mac/Widget0.7.0/build20与服务端已升级。新增独立睡眠读取，沿用现有HC活动通道；官方小米运动健康、手表应用、表盘和绑定保持。

- 血糖图用淡紫色显示HC睡眠会话、淡绿色显示锻炼会话；跨午夜/窗口边界正确裁剪，不改变血糖纵轴。手机另有两条紧凑区间条；Mac与组件共用图表。原始区间与手动生活标记分别保留。
- 简洁动态24h、固定日报与两类主动详细解读加入睡眠/锻炼原始区间及对应观察血糖统计。锻炼包含前30min/期间/后60min，未结束不计算后效应；固定截止之后的醒来/锻炼结束时间不进入AI上下文。睡眠会话可能含清醒，不推算实际睡着时长或分期。
- 手动分析75%准入、历史完整日95%比较、30min调用间隔和详细报告纯手动生成规则保持。旧报告不自动改写；下次生成采用新输入。简报方法为`cgm-observation-5`。

## 安装与授权

制品：[Android APK](glucose-watch6-0.7.0.apk)、[Mac应用](OttaiMirror-0.7.0.zip)、[校验和](SHA256SUMS)、[合成样式预览](sleep-exercise-synthetic.png)。覆盖升级保留本设备私密配置；公开制品不含真实健康记录或令牌。

在手机「运动与血糖」点击「授权锻炼、心率、步数、热量与睡眠」，由用户在系统页允许新增睡眠读取，再同步最近48小时。已有4类授权可继续单独运行。只读取来源`com.mi.health`，不增加睡眠阶段、标题、备注、位置或路线；没有源记录时不绘制虚假区间。
