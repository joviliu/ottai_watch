# 血糖、心率与活动时序 0.4.2

2026-11-10。Android versionCode16；Mac/Widget build13。两端沿用原签名/标识，可覆盖；无需改动官方小米运动健康、手表绑定、RPK或表盘。

- Health Connect：读取官方小米共享的心率、运动会话、活动能量，以及实际可用的步数；活动能量为不含基础代谢的估算 kcal。
- 官方系统计步 Provider：独立只读补充手机步数，需身体活动授权；没有新传感器注册、GPS或唤醒锁。手机未携带时可能漏记。
- 云端按来源、权限、新鲜度和原始分辨率选择单一的步数来源；保留 HC 心率，避免把手机和手表步数相加。原始区间保留，批次时长不用于计算步频/强度。
- Mac主界面、通知中心组件和手机云图表采用相同24h横轴：蓝色血糖主图、独立bpm心率点/范围、独立缩放的绿色步数与琥珀色估算能量细柱。粗粒度日汇总不制造分时尖峰；缺测不表示静止。
- AI输入加入完整15分钟原始起点分组时序、覆盖与来源说明；原始例子有明确截断，区间总量不均摊。能量可能由同源心率/运动算法估算，不作为独立证据或换算步数。

安装前核对 [SHA256SUMS](SHA256SUMS)。[手机APK](glucose-watch6-0.4.2.apk) 直接覆盖。Mac解压 [OttaiMirror-0.4.2.zip](OttaiMirror-0.4.2.zip)，退出旧进程后替换同一路径的应用，避免同时保留多个已注册副本；新环境优先按 [Mac安装脚本](../../macos/install.sh) 和 [云交接](../../docs/CLOUD_SYNC_HANDOFF.md)配置自己的私密只读连接。制品不含连接令牌或健康资料。
