# 0.1.12 表盘：每 8 小时随机协调双色

仅更新表盘 BIN/ZIP。手机继续 0.1.11，手表应用继续恢复版 RPK 0.1.10 / code 11，无需重装。沿用 ID `8670260101` 覆盖当前单款表盘，不安装第二款。
