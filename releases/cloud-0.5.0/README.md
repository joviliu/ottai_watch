# 重点报告、生活标记与餐食照片 0.5.0

Android手动分析HTTP400已在[0.5.1](../cloud-0.5.1/README.md)修复，请使用新版手机APK；本版Mac安装包仍为当前版本。

2026-11-10。Android code18，Mac/Widget build18。官方小米运动健康3.59.2、手表绑定、RPK与表盘保持；Mac状态栏沿用0.4.6样式。

- 分析改为简短摘要与最多三张彩色重点卡片，突出值得关注的形态、变化及建议；不再逐段复述曲线，不重复固定免责段落。相关研究依据折叠并按主题去重，旧报告仍可展开。
- 手机补齐动态24h主动分析及「动态24h／每日回顾」切换；两类报告各自保存，原完整性、30分钟间隔和同快照复用规则保持。
- Mac图表悬停显示时间准星，点击记录进餐、入睡、起床、运动或备注；手机点按/横拖选时。标记可编辑/软删除，跨端版本冲突不会静默覆盖。
- 手机进餐可手填食物和可选热量范围，或拍照/选图后显式识别。结果可修改、确认后才写成进餐；图片去元数据并压缩，原图不进入服务数据库/日志。
- 照片使用独立Ali relay、SG worker和每日30次预算，不挤占原49次血糖分析预算。界面展示实际token与估算费用，未知结果不自动重发收费。

[Android APK](glucose-watch6-0.5.0.apk)与[Mac应用](OttaiMirror-0.5.0.zip)覆盖现有安装，先核对[SHA256SUMS](SHA256SUMS)。Android必须沿用原签名；Mac优先按[安装脚本](../../macos/install.sh)覆盖同一路径，保留现有私密连接配置及单实例。安装包不含令牌、真实健康资料或用户照片。

服务端增量迁移保留旧CGM、活动和报告，新增生活标记、研究主题及识别任务表；先备份、停旧进程，再切换新代码。接口、照片约束及独立服务部署见[FOOD_EVENTS](../../server/FOOD_EVENTS.md)，新环境从[云接续](../../docs/CLOUD_SYNC_HANDOFF.md)开始。

本地及Ali Python3.6服务测试68项、worker测试4项、Android策略/Watch回归、Mac模型/网络交互测试与两端Release构建通过。两端0.5.0已安装，Mac真实时间准星、记录弹窗和保存通过；用户确认的记录已跨端同步，真实方法v4动态报告约291字、三项重点，两端显示正常。相机打开/取消通过。
