# 0.1.10：圆点布局与通知图标

先在本目录运行 `shasum -a 256 -c SHA256SUMS`（Linux 可用 `sha256sum -c SHA256SUMS`）。

| 文件 | 用途 |
| --- | --- |
| `glucose-watch6-0.1.10.apk` | 手机端 versionCode 11，蓝底白折线应用图标、透明白色通知小图标 |
| `ottai-minimal-watch6.bin` | 同 ID `8670260101` 的 Ottai Ultra 表盘：6×14 圆点时钟，数字间距加宽，白色小时、橙色分钟，无冒号；血糖区下移，采用较小的稀疏5×7亮紫色数字，更新时间在左，趋势在右 |
| `ottai-minimal-watch6.zip` | 同一表盘的 Mi Fitness 开发入口封装；本次仍使用 BIN 通过本地 SPP 上传 |
| `ottai-watchface-installer-0.1.4.apk` | 临时本地表盘上传工具，完成后卸载，不参与日常同步 |

手表应用继续使用 [0.1.8 RPK](../0.1.8/glucose-watch6-0.1.8.rpk)，无须重复升级。本轮仅覆盖更新当前 ID，没有安装第二款；以后制作不同风格时可使用独立 ID，并共享同一份血糖文件。

手机与 RPK 包名及证书保持一致，自动同步策略未改变；这是界面调整。当前表盘上传及恢复后的文件更新回执已验证，用户已确认最终布局合适、显示正常，见 [验证记录](../../docs/validation.md)。

新增显示配色：血糖一位小数在 `[3.9, 7.8]` 为紫色，`(7.8, 12.0]` 为黄色，其余红色；趋势箭头跟随数值，旧数据同色系变暗并保留 `OLD` 与原时间。这是用户指定的显示规则。

通知左侧图标已在实际手机上确认显示蓝底白折线。此次 HyperOS 曾缓存旧机器人头像，单独重启本应用未刷新；在用户授权正常重启手机并恢复连接后，实际通知已显示新图标。不要为刷新图标清除应用或系统数据。

完整步骤见 [安装与排查](../../docs/install.md)、[表盘工程](../../watchface/README.md) 和 [接续文档](../../docs/HANDOFF.md)。不含配对凭据、私钥或健康日志；安装缩略图血糖使用占位，示例预览为合成数据。
