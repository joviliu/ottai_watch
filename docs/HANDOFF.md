## 用户要求

- 保留旧读数及其测量时间；有缓存时不清空成 `--`，不能把旧值标成刚更新。
- 跟随 Ottai 约 5 分钟更新；优先省电，不做秒级传感器轮询。
- 小部件/表盘必须在用户不手动打开“血糖镜像”时随新数据变化。仅显示上次打开应用导出的文件不算完成，至少验证两个更新周期。
- 按用户最新参考缩短时钟并增大圆点，日期紧凑；下方突出血糖及方向箭头，无单位和曲线，保留原始更新时间，显示电量和心率。
- 本轮仅单款 Ottai Ultra，ID `8670260101`，覆盖此前同 ID 样式。[layout.json](../watchface/layout.json) 是唯一布局参数源；时钟 6×14、90×232，x=8/116/226/334、y=68..300，约占屏幕上方 3/5，小时白色、分钟 `#ff682b`、无冒号。
- 血糖使用稀疏 5×7 单点笔画，数字 40×56、小数点 12×56、间距 4 px，y=352 自动居中；数值与右趋势按显示值同步配色：`3.9 <= v <= 7.8` 紫 `#924ff7`，`7.8 < v <= 12.0` 黄 `#ffd60a`，其余有效值红 `#ff453a`；过期在同色系变暗，仍保留 `OLD`。左时间 y=365、28 px 亮色，过期另起一行 `OLD`；右趋势 y=353，日期、电量和心率不变。未来不同风格可用独立 ID 并存并共用 RPK/文件，本轮不安装第二款。
- 手机 0.1.10 增加兼容 PNG 图标，通知 smallIcon 使用白色透明背景折线 vector，移除右侧重复 largeIcon；资源与系统加载检查正确，正常重启后稳定截图已确认通知显示蓝底白折线，无重复大图标。没有取得原厂“极简风大数字”可编辑工程，也不分发其素材。

## 优先接续步骤

1. 先读 [表盘工程](../watchface/README.md)、[协议](protocol.md) 与 [验证状态](validation.md)。0.1.10 单款覆盖、用户最终目视与重启后通知图标均已通过；恢复后一轮自然通知也已完成文件导出与 ACK，约 9.8 秒。追加动态颜色已安装并通过桌面边界验证；用户此前目视确认的是同布局静态紫色版，本次未额外确认真实范围切换。配色按用户自定义显示分段处理；布局不再改动，手机 0.1.10 / RPK 0.1.8 不变。新环境仍需按相同标准复验。Mi Fitness 开发入口授权 404 仍未修复，表盘升级沿用本地 SPP。
2. 0.1.8 基线验证时手机“表盘自动同步”已启用。用户已确认自动返回点阵表盘后读数、水平箭头和原始时间正常，十几秒的观察延迟可接受。随后手机锁屏、不手动打开表端，连续两轮自然 Ottai 更新都触发 `FACE_WAKE`、`FACE_EXPORT` 和 ACK，测量时间推进 5 分钟且数值变化，通知接收到 ACK 分别约 9.8 秒和 9.7 秒；该耗时不是屏幕显示延迟。用户已确认最新一轮数值、水平趋势及原始测量时间正确，自动返回正常，未报告明显闪屏或卡住。开发版基本验收通过。
3. 新环境复验时核对每轮完整读数身份、文件导出回执、表盘原始测量时间以及数值/趋势；仅有 SDK success、ACK 或旧缓存文件不能通过验收。若无显示变化，排查 Lua 的本包候选路径与当前文件，不先认定后台已经成立。
4. 继续检查断连旧数据、休眠恢复、长按换表盘、在其他页面被唤起时的行为；AOD、长期稳定性和耗电另测。自动同步开关新安装默认关闭，当前设备开启状态不可当作新环境默认。
5. 需升级表盘时参考 [临时 SPP 安装器](../tools/spp-installer/README.md)。安装器 0.1.4 的 `replace` 只按当前 BIN 目标删除并独立查询确认后上传，本轮仅 ID `8670260101`，另一个 ID 只是未来预留；`am start -S` 必须等上轮 `DISCONNECTED`，保留其他表盘和配对。
6. 安装器占用蓝牙期间若暂停了桥接应用，结束后及正常重启后都要恢复并实际核对原运行状态和此前已授权的通知监听；不要仅信 `pm` 命令输出。实测 `disable-user` 曾清除镜像和 Mi Fitness 的通知访问；恢复后须核对最新 Ottai 通知确实进入镜像，避免继续显示旧缓存。

## 0.1.8 同步契约要点

- `face_export` 包含完整 `frameKey`，手机仅承认当前身份并存储 `faceExportKey`。
- 文件发布串行执行，只保留最新 pending 帧；被更正覆盖的旧完成不确认或自动退出，已写同身份可省略重复 I/O。
- 手机待同步会话绑定 `faceSyncKey`，不因固定秒数过期而丢失延迟启动时的返回标志；回执、手机主动打开或新身份会清理旧会话。
- 表端新合法帧先取消退出定时器，保留返回意图到最新帧发布；退出前再次核对身份。离页清理退出定时器和意图。

这些是当前源码契约；0.1.8 已有连续两轮锁屏自然更新及用户确认，0.1.10 完成最终布局目视、图标及重启恢复后自然周期验证；异常状态和长期表现仍需继续验证。真实趋势目前仅观察到水平箭头，斜箭头等方向已经映射测试，尚无实际变化序列的目视证据。

表盘黑屏曾由错误的 Lua anchor 资源索引造成：上游称为 `sentinel` 的字段实际指向 Lua 入口，默认 `n-1` 在本项目指向了趋势 PNG；当前 `build.py` 按 `lua/main.lua` 文件名确定入口并在打包/解包后断言。不要硬编码当前资源顺序的索引。
