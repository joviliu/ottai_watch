# 每日血糖观察方法（成人、未确诊糖尿病）

方法版本 `cgm-observation-3`，更新于 2026-11-10。目标是解释本人的连续血糖观察和跨日变化，不能据此诊断糖尿病/糖前期或调整药物。截图仅用于界面参考；没有从图片描出虚构的历史样本或向数据库写入截图统计。

## 范围和证据

| 依据 | 用于本项目 | 不作出的推断 |
| --- | --- | --- |
| [Shah 等，2019，健康非糖尿病人群前瞻研究](https://pubmed.ncbi.nlm.nih.gov/31127824/) | 3.9–7.8 mmol/L 可作为研究中的描述性观察区间，与用户原设置一致 | 研究样本的范围占比中位数不是本人的必须达标值；单日超出不等于病情恶化 |
| [国际 CGM Time in Range 共识，2019](https://doi.org/10.2337/dci19-0028) | 公开报告覆盖率、范围内/外时间、均值和变异；14 天且充分覆盖更有代表性 | 糖尿病人群 3.9–10.0、TIR 或 CV 治疗目标不直接用于评判未确诊者；三天不能替代长期资料 |
| [ADA 诊断与分类标准，2026](https://doi.org/10.2337/dc26-s002) | 明确 CGM 资料不足以筛查/诊断糖前期或糖尿病；需要时与医生讨论适当的实验室检查 | 不以传感器图形代替 HbA1c、空腹血浆血糖或 OGTT，不推算诊断 |

本人的 3.9–7.8 标为「观察区间」，不根据一天截图自动更改个人医学目标。3.9–10.0 另存为带人群说明的补充统计，不能把它显示为本人的首要达标目标。

## 原始资料与确定性统计

- 每条资料为原始测量时间、mmol/L 数值、原始/规范趋势及接收时间。按测量时间幂等，同源更正保留审计。历史未知趋势标记 `?`，不用模型补造。
- 保留原始测量值。每点只覆盖其后最多五分钟，下一点更早则缩短，窗口边缘裁剪；长缺口不插值、不视作正常。按实际观察时长加权计算均值、总体 SD、CV 及区间占比，同时显示覆盖率。极值来自有效观察，不能因画面平滑而删除真实峰谷。
- 覆盖率分母为完整报告时窗，区间比例的分母为已观察时间，两者明确分开。没有资料时数值为 null，不能用 0 代表正常。
- 图表保留最近 24h 测量点，断开明显缺测。浅灰参考曲线先计算每一天各半小时桶的中位数，再跨日计算中位数和四分位，避免某天样本较多而占据更大权重。参考桶公开参与天数，不填补没有观察到的时段。
- 最近 24h 原始相对分钟/数值可送给模型辅助读图；近期逐日资料和更远历史仅发送带覆盖的汇总。原始长期资料仍留在 Ali，不因压缩模型输入而删除。

## 每日一次的解释

北京时间每天 08:15 尝试一份覆盖前一自然日00:00–24:00的固定日报，同时比较前一个 24h、近 7d 与前 7d、近 14d 与前 14d，并使用更远的分段汇总判断是否存在持续形态。没有独立周报模型任务。超过 72h 只表示允许开始初步报告，资料不足仍须明确展示；不把历史跨度当成完整采集时长。

程序计算并提供全部指标，模型只解释这些指标。比较覆盖不齐、缺测集中在特定时段、历史太短或设备更换等限制；不允许把下降的均值一律解释成改善，必须同时考虑偏低读数、偏高时间、波动与覆盖。没有饮食/活动/用药记录时，不命名某个餐次或推断原因。

模型输入含受控方法说明，输出结构化 summary、sections、limitations；来源由程序附加，不接受模型编造链接。提示词见 [daily_prompt.md](../server/daily_prompt.md)，统计实现在 [statistics.py](../server/statistics.py)。日报不替代对当前不适的即时判断，也不提供剂量或停药建议。

## 调用、存储和验证边界

Ali 的 SQLite 保存原始值、同源更正、报告及每天调用 claim。claim 在网络请求前提交，不确定结果不自动重发。收集/展示不依赖模型在线；最近一次报告失败时保留旧报告日期并标明状态。

仅向指定 SG 转发匿名观察资料，OpenAI Key 由 SG 的 systemd credential 从用户指定文件加载。手机和 Mac 只持有本应用独立设备令牌；Mac 使用只读令牌。请求使用 `store:false`，它不等同于供应商的 Zero Data Retention 承诺。接入遵循 [OpenAI 结构化输出文档](https://developers.openai.com/api/docs/guides/structured-outputs)。

自动测试以合成数据验证范围边界、缺测和时间加权、同源更正、覆盖不足、历史聚合、鉴权隔离、每日 claim 和失败处理。真实长期资料及日报效果必须随实际积累继续核对；三天或更长历史不会通过注入合成资料来提前满足。

## 动态24h与固定日报

0.3.0增加手动动态报告：截至最新测量的滚动24h，时间跨度满24h、覆盖≥95%、最长未观测缺口≤15min、最新读数10min内后可用。这是产品完整性门槛，不代表医学代表性已成立。每次手动请求至少间隔30min，跨重启与设备持久生效；无额外3次/日限制。同一数据快照复用、不重发未知执行结果。自然日固定日报仍在真实资料跨度超过72h后每天08:15运行。两类独立保存并在同一文本区切换；报告明确各自起止时间。

## 候选波动、健康参考与个人比较

- 候选检测以之前30min稳定基线中位数为锚，45min内至少3点跨10min持续上升≥0.8mmol/L才记录；以上是本项目描述性启发式，未作为临床/餐检模型验证。上升起点不是提前看45min搜索的起点，而是确认前最后一个近基线点。3点中位数定位持续峰，全天原始最高/最低值仍不平滑。
- 持续峰与基线的幅度/分钟、实际已观察下降及回近基线分别计算。回到基线+0.3需两点；超过10min源间隔不连接，观察最多4h。缺口、窗口结尾或4h上限时，完整恢复分钟保持null，不能误报已恢复。报告重点展示至多3次显著候选，显示全部候选数/截断状态供模型理解。
- 候选可作为回顾可能进餐的时间锚点；不倒推精确进餐时刻，也不把波动定性为饮食不健康。[健康成人CGM-only餐检原始研究（2026）](https://doi.org/10.1038/s41598-026-50699-5)显示漏检、误检与检测延迟之间存在取舍；该研究不能验证本项目启发式。
- [Shah2019](https://doi.org/10.1210/jc.2018-02763)的研究均值约5.5mmol/L、个体内CV均值约17%、3.9–7.8占比中位数96%（IQR93–98）只作标注人群与设备差异的描述参考，不设为个人达标线或虚构一条通用理想餐后曲线。
- 自身参考取此前7天及较早第15–28天内覆盖≥95%的完整日，至少3日才提供日指标中位数和本期差值。前24h比较须同样检查完整性，长期参考保留既有56d日汇总/更早28d块。单日异常与多日持续形态分开，均值降低须同时考虑偏低、波动、覆盖和干预记录。
- 生理解释基于[Endotext胰岛素敏感性评估](https://www.ncbi.nlm.nih.gov/sites/books/NBK278954/?report=reader)、[Endotext胰高血糖素生理](https://www.ncbi.nlm.nih.gov/sites/books/NBK279127/)和[β细胞功能综述](https://doi.org/10.1210/endrev/bnab021)。曲线共同反映吸收、分泌、组织利用、肝糖输出及活动/测量等因素；单独CGM不能区分具体激素功能。仅提出有支持/替代解释的参考性假设及记录验证方式，不由波形反算胰岛素/C肽、HOMA或诊断β细胞衰竭。

## 活动背景与共同时间轴（0.4.2）

活动是可选的描述性背景，不改变原有血糖统计与分析就绪门槛。经用户授权，HC只读官方运动健康的运动会话、心率、步数和估计活动能量；手机官方Provider可独立补充步数。保留原始来源、设备元数据、采样时间、容器区间和同步时间；不预设记录全来自手表。每次分析在完整两日窗口内选定一个步数来源，前后期沿用同一选择，不将手机与HC步数相加。

心率按真实采样汇总为15分钟分析桶，保留样本数、实际首末时间、均值/最小/最大和滞后；无样本不插值、不推算静息心率或强度。步数和活动能量完整按原始起点作15分钟分组，保留粗粒度、跨周期、重叠、零时长与未来容器标记。原始例子数量有界，但完整分组不丢早期资料。查询成功时窗不等于佩戴覆盖，缺测不能解释为静止。手机区间是批边界，不将极短边界解释为连续步行时长、步频或强度。

活动能量只指HC `ActiveCaloriesBurned` 的设备估计千卡，原生小卡除1000；不包含基础代谢或总能量，也不代表饮食热量、代谢率或可换算的步数。只有设备信息确实支持可穿戴来源时才讨论对未携带手机时段的补充。能量往往使用同设备心率等估计，不能把两者当独立证据重复增加置信度。重叠、粗粒度、跨窗口或未来结束资料有显式限制；无可靠窗口总量时保持null，不以原始字段和冒充完整消耗。

既有运动会话提供前30分钟/运动中/后60分钟的血糖时间加权统计与覆盖；候选餐后样波动只核对时间重叠。上述窗口是本项目描述性选择，未作为临床归因窗口验证。结合 [ADA活动立场声明](https://doi.org/10.2337/dc16-1728)和 [ACSM2022共识](https://pubmed.ncbi.nlm.nih.gov/35029593/)讨论可能关系及替代解释；后者人群为2型糖尿病，治疗指标或运动处方不直接套用未确诊成人。时间关联不能证明活动改变了胰岛素敏感性、β细胞或其他激素功能。

手机、Mac和组件使用同一24h横轴，血糖、心率及两个活动条轨分开纵轴/相对比例。公开HR为5分钟实测汇总点与范围线，AI为15分钟汇总；图表活动桶只画完整落在观察窗、时长大于0且不超过15分钟的原始短区间，整日/粗汇总只在摘要提示，不伪造细时序。柱高表示各自相对记录量，不是跨单位活动评分或强度。实现及真机边界见 [活动接续](HEALTH_CONNECT.md)。
